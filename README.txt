D2S Helper v2.40 - D2 Survivors 자동 진행 도우미 (설정은 공포 영역 단계 하나, 나머지는 정해진 규칙)

[설치] Python 3.9 이상 설치 후 install.bat 한 번 실행
[실행] run.bat -> "시작 (F8)". 즉시 중지는 F9.
       게임 창 제목은 "D2 Survivors" 그대로, 창 모드로 실행. 미니맵은 켜 둔다(Tab).

[규칙]
[단계] 화면 위 "공포 영역 단계" 칸에 숫자 입력 -> 그 단계만 반복. 비우면 목록 맨 위의 새로 열린 단계.
       정한 단계가 아직 깬 목록에 없으면(죽어서 진행도를 잃은 경우 등) 목록 맨 위의 새로 열린 단계로 대신 진행.

1 마을   : 웨이포인트 -> 정한 공포 영역 단계로 입장 ('완료한 단계 다시 하기' 목록).
           목록의 줄 글자를 확인한 뒤에만 누름. 이름표가 없으면 파란 불꽃(받침)을 클릭.
2 사냥   : 보스가 죽어 '차원문이 열렸습니다'가 뜰 때까지 움직이지 않음.
3 줍기   : 보스 처치 순간 서 있던 자리에서 상하좌우 '줍기 반경'(기본 10m, 캐릭터 키 2m 기준) 안에서만 움직임.
           화면의 "줍기 반경" 칸에서 바꿀 수 있음 (2~30m, 시작할 때 적용).
           위치는 미니맵의 포탈 표시와 내 십자 사이로 재므로 어긋나지 않음.
           - 정수·열쇠·부적 이름이 화면에 보이면 가장 먼저 클릭해서 주움.
           - 반경 안을 안쪽부터 나선형으로 마우스를 누른 채 달림 (최대 45초).
           - 반경 안의 미니맵 세트·유니크·주얼 표시로 이동. 반경 밖 표시는 무시.
           - 포탈은 누르거나 밟지 않게 피해서 다님 (다 끝난 뒤에만 클릭).
           - 반경 밖으로 나가면 즉시 안으로 돌아옴. 포탈 표시가 미니맵에서 사라지면 포탈 쪽으로 돌아옴.
           전체 70초 안. 85초가 지나면 열린 창을 닫고 무조건 포탈.
4 정리   : 인벤토리에 무언가 있을 때만 대장장이에게 감.
           새 유니크·세트 -> 등록('수집'), 이미 등록된 것 -> 판매 (유니크 부적 3종은 보관)
           정수·룬·작은 부적·거대 부적 -> 보관함 (개인 -> 공유1 -> 공유2 -> 공유3)
           나머지 -> 판매
5 다음 판: 포탈 클릭. 죽거나 판이 끝나면 Esc로 마을에 가서 같은 단계를 다시 고름.
           (단계를 비워 두면 Enter로 게임이 정한 단계를 이어 감)

[안전]
- 게임 창이 맨 앞일 때만 클릭/키 입력.
- 대장장이·보관함·인벤토리·웨이포인트 창이 열려 있으면 이동 클릭을 보내지 않음.

[기록]
- 시작할 때마다 records 폴더 아래에 그 회차 기록(log.txt + 단계별 게임 화면)을 남김. 최근 5회분 보관.
- 문제가 생기면 "기록 폴더 열기" -> 그 폴더를 압축해서 보내 주세요.

[휴대폰] 화면의 주소를 같은 와이파이의 휴대폰 브라우저에서 열면 진행 상황 확인.

  이 추정이 실제 게임에서 틀려 엉뚱한 곳으로 계속 달려감.
- 수정: 위치는 오직 미니맵의 포탈 표시와 내 십자 사이로만 잼. 추정 위치로 움직이는 동작은 모두 제거.

  - 포탈 표시는 프레임마다 같은 표시를 따라감 (다른 빨간 표시로 갈아타지 않음).
  - 미니맵 유니크·세트·주얼 표시도 포탈 기준 좌표로 추적 (추정 없음).

  - 포인터를 캐릭터 앞쪽 가까이(화면 높이의 22% 이내)에만 둬서 버튼을 떼도 멀리 가지 않음.

  Esc -> 메뉴의 '저장 후 나가기' 클릭 -> 마을에서 새 판 시작. 실패하면 30초 뒤 다시 시도.

  2분 이어지면 무조건 Esc -> '저장 후 나가기' -> 마을 -> 새 판.

[v2.14 변경] 게임 창을 앞에 두지 않아도 동작
- 게임 창이 다른 창(브라우저 등) 뒤에 있어도 그대로 동작. 진짜 마우스·키보드는 건드리지 않음.
  - 화면: 가려진 창도 그대로 읽는 방식(PrintWindow)으로 읽음.
  - 입력: 클릭·키를 게임 창에 직접 보냄 (마우스 커서가 움직이지 않음).
  - 게임 창이 맨 앞일 때는 예전처럼 실제 마우스·키보드 사용.
- 게임 창을 자동으로 앞으로 가져오는 동작은 없앰.
- 최소화되면 다른 창 뒤로 다시 띄움 (앞으로 오지 않음).
- 게임이 가려지면 그림을 멈추는 경우 대비: "게임을 '가려져도 동작' 모드로 다시 실행" 버튼
  (게임을 껐다가 계속 그리도록 하는 옵션을 붙여 다시 켬). 한 번만 하면 됨.
